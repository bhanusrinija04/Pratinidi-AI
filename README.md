# Pratinidi AI – Smart College Announcements

Pratinidi AI is an AI-powered college announcements platform designed to help students understand important campus updates more easily. It uses AI to summarize announcements and extract eligibility information, making relevant information easier to find.

## 🎯 Project Overview

College announcements can contain lengthy information about events, opportunities, deadlines, and eligibility criteria. Pratinidi AI aims to make these updates easier to understand through AI-assisted summarization and information extraction.

## ✨ Key Features

- **AI-Powered Summarization:** Generate concise summaries of college announcements.
- **Eligibility Extraction:** Help identify eligibility criteria from announcement content.
- **Real-Time Updates:** Support timely access to announcements.
- **Authentication:** Provide user authentication.
- **Role-Based Access:** Support different access permissions based on user roles.

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Backend and Data:** Supabase
- **AI Integration:** Google Gemini API
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## ⚙️ How It Works

1. College announcements are made available through the platform.
2. The AI integration processes announcement content.
3. Gemini AI helps summarize the content and extract eligibility details.
4. Users can review the information to understand important updates more quickly.

*The exact workflow depends on the features implemented in the current codebase.*

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Access to the project repository
- Required Supabase and Gemini configuration, if used by the application

### Installation

Clone the repository:

```bash
git clone YOUR_PRATINIDI_AI_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

### Environment Variables

If the application requires API credentials, configure them in a local `.env.local` file according to the variable names expected by the project.

**Security note:** Never commit API keys, passwords, or private credentials to GitHub.
